# ST-04 — بانک خون
شاخه مستقل از ST-03 ادغام‌شده. مرجع: bloodbank-dashboard، inventory، crossmatch، requests، temperature، thawing، reports و crossmatch-updated در Raw.
۱. مدل داده واحد مستقل، نتیجه آزمایش، رویداد گردش واحد و ثبت دما؛ Migration و قواعد وضعیت.
۲. CQRS و API با مجوز صریح، scope مرکز، کنترل rowversion، تراکنش رزرو و کنترل تعداد اقلام درخواست.
۳. دریافت/بازرسی، ثبت نتیجه آزمایش مستند، رزرو و ذوب، آماده تحویل، قرنطینه/لغو رزرو/امحای ثبت‌شده، برگشت درخواست برای بازبینی.
۴. داشبورد، موجودی، کارتابل بانک، Crossmatch، دما، ذوب و گزارش، استفاده مجدد از اجزای ST-03.
۵. Seed، تست SQL و مرورگری و مستندات.
حدود: ST-04 فقط ثبت و آماده‌سازی نرم‌افزاری است؛ صدور و تحویل فیزیکی ST-05. هیچ الگوریتم بالینی یا محاسبه خودکار سازگاری/عمر پس از ذوب؛ سیاست بیمارستان، اعتبارسنجی تخصصی، کالیبراسیون و اتصال تجهیزات لازم است. نتیجه پذیرفته‌شده توسط کاربر مجاز، بررسی نسخه پذیرش، تاریخ انقضا و وضعیت ثبت‌شده تجهیزات شرط نرم‌افزاری هستند، نه مجوز پزشکی. هر واحد یک شناسه مستقل؛ دریافت گروهی نیازمند فهرست کدهای واقعی هر کیسه.
