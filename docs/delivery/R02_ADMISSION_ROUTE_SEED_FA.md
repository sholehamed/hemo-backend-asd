# R02 — پایلوت مسیرهای پذیرش
مبنای بک‌اند: ST09 merge 9edf81cc. فعال‌سازی اختیاری: HemoSeed:IncludeAdmissionRouteMenus=true در محیط Development همراه با HemoSeed:Enabled=true. هیچ کاربر یا API جدید، migration، grant عمومی یا grant تمام منو اضافه نمی‌شود.
مسیرهای دقیق Guard شامل :guid و APIهای لازم/اختیاری در HemoAdmissionRouteSeed.Routes ثبت شده‌اند. هر مجوز جدید صفحه فقط تکرار ApiGUID صریح موجود روی منوی اصلی همان نقش آزمایشی است و نقش فقط اگر تمام پیش‌نیازهای لازم را دارد به صفحه دسترسی می‌گیرد. مسیر detail از منو پنهان است. برای فرم ایجاد، دسترسی detail برای navigation بعد از ثبت لازم است ولی GET detail روی منوی فرم ایجاد ثبت نمی‌شود.
پیش‌فرض غیرفعال است؛ seed قبلی و حساب‌های فعلی بدون تغییر. منوهای پایلوت sibling منوی اصلی‌اند تا لینک داشبورد اصلی از دست نرود؛ ساختار Package و SubPath شرکت باید پیش از اتصال عملی تعیین شود. تعارض مسیر موجود با marker اختصاصی باعث خطا می‌شود. این seed تنها برای دیتابیس آزمایشی است و پس از فعال‌سازی، مجوز هر صفحه مستقل است؛ حذف مجوز ریشه به تنهایی معادل حذف grant صفحه فرعی نیست.
تست‌ها: پوشش هشت مسیر، منع ایجاد برای viewer، مدیر آمار فقط stats، SQL opt-in و اجرای مجدد بدون تکرار، ثابت ماندن مجموعه role/API، پنهان بودن detail و منع review برای نقش فاقد پیش‌نیاز. CI هنوز تأیید نشده. اتصال Login، Package، RefreshToken، سایر مسیرها و E2E واقعی R02 باقی مانده است.
