# کاربران و نقش‌های ST-04
مرکز آزمایشی مشترک همان بیمارستان آزمایشی HEMO است. حساب‌های ST-02 و ST-03 حفظ می‌شوند.
| نام کاربری | نقش | دسترسی |
|---|---|---|
| hemo.bloodbank | کارشناس بانک خون (موجود) | صف درخواست تأیید شده، موجودی و سوابق، دریافت، ثبت آزمایش، رزرو، ذوب، آماده‌سازی، قرنطینه، لغو رزرو، ثبت دما |
| hemo.bank.supervisor | مسئول بانک خون (جدید) | همه موارد کارشناس + تأیید بازرسی و ورود به موجودی، ثبت امحا و برگشت درخواست به ثبت‌کننده |
اختصاص مجوز فقط به نقش‌های آزمایشی؛ در محیط واقعی مدیر سامانه از ساختار RoleAccess/MenuApi موجود استفاده می‌کند. برای آزمایش:
```powershell
$env:ASPNETCORE_ENVIRONMENT = 'Development'
$env:HemoSeed__Enabled = 'true'
$env:HemoSeed__IncludeBloodBank = 'true'
$env:HemoSeed__Passwords__BankSupervisor = Read-Host 'Password for hemo.bank.supervisor'
dotnet run --project web/web.csproj --no-launch-profile
```
این فلگ ST-03 را نیز فعال می‌کند. در دیتابیس خالی رمزهای شش حساب قبلی را طبق اسناد پذیرش و درخواست نیز تعیین کنید. رمزهای متفاوت حداقل ۱۶ کاراکتری؛ بدون رمز ثابت. در اجرای مجدد رمز موجود عوض نمی‌شود و مجوز جدید برای نقش آزمایشی بانک اضافه می‌شود. هیچ داده واقعی بیمار یا فرآورده seed نمی‌شود. نیازمند تنظیمات اتصال و Identity شرکت است.
