# R02 — تکمیل دسترسی صفحات بانک خون
مبنا: main 0e9fa689؛ PR19 ادغام شده. همراه Frontend PR25.
## فعال‌سازی Development
HemoSeed__Enabled=true، HemoSeed__IncludeBloodBank=true، HemoSeed__IncludeBankCompletePages=true. گزینه آخر صفحات خواندنی و واحد را نیز فعال می‌کند. گزینه‌های قبلی درخواست خون و پذیرش حفظ شوند.
- /hemo/bank/crossmatch: موجودی، مجوز آزمایش، صف و جزئیات درخواست لازم است؛ برگشت درخواست فقط با مجوز موجود bank-return.
- /hemo/bank/thaw: موجودی و مجوز ذوب لازم است؛ درخواست مرتبط فقط با مجوز قبلی جزئیات.
- /hemo/bank/temperature: ثبت یا تاریخچه دما؛ هر عملیات با مجوز مستقل خود.
- /hemo/bank/lab-history: فقط مجوز تاریخچه آزمایش.
حساب‌های hemo.bloodbank و hemo.bank.supervisor موجود هستند؛ برگشت درخواست برای مسئول بانک. مدیر آمار به صفحات عملیاتی دسترسی ندارد. هیچ زوج نقش/API تازه، حساب یا رمز جدید، Migration یا اجرای Production ایجاد نمی‌شود.
## تست
یک تست سیاست جدید و توسعه تست SQL موجود برای ارتقا، نگاشت دقیق، حفظ مجوزها و تکرارپذیری. CI و UAT واقعی هنوز تأیید نشده‌اند. عملیات سرور و قواعد بالینی موجود دست‌نخورده‌اند.
