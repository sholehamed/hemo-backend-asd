# کاربران ST-05 و داده تمرینی
| حساب | نقش / دسترسی جدید |
|---|---|
| hemo.nurse | دریافت بخش، مغایرت، تطبیق، شاهد مستقل، شروع، پایش، پایان/توقف، مرجوعی |
| hemo.nurse.witness | جدید؛ فقط مشاهده حواله‌ها و تأیید مستقل شاهد |
| hemo.doctor | پرونده تزریق، پایش خواندنی، یادداشت مستند و ثبت توقف |
| hemo.bloodbank | مشاهده حواله‌ها، دریافت مرجوعی |
| hemo.bank.supervisor | صدور، حمل، مرجوعی، تأیید دریافت و ثبت امحا |
نقش‌های پیشین و رمزها حفظ می‌شوند. هیچ رمز پیش‌فرض یا دسترسی عمومی تعریف نشده است.
```powershell
$env:ASPNETCORE_ENVIRONMENT = 'Development'
$env:HemoSeed__Enabled = 'true'
$env:HemoSeed__IncludeTransfusion = 'true'
$env:HemoSeed__IncludeTransfusionSamples = 'true'
$env:HemoSeed__Passwords__WitnessNurse = Read-Host 'Password for hemo.nurse.witness'
dotnet run --project web/web.csproj --no-launch-profile
```
قبل از اجرا Migration را روی دیتابیس توسعه اعمال کنید و برای حساب‌های قبلی ایجادنشده رمزهای مستقل ۱۶+ کاراکتری مطابق راهنماهای قبلی تنظیم کنید. IncludeTransfusion شامل مراحل قبلی است؛ IncludeTransfusionSamples اختیاری است و خودش IncludeTransfusion را فعال می‌کند.
چهار سناریوی کاملاً ساختگی در بیمارستان آزمایشی HEMO ایجاد می‌شود؛ از کد پرونده DEMO-ST05-01 تا 04، دستبند DEMO-WRIST-01 تا 04، کیسه DEMO-UNIT-01 تا 04 و درخواست DEMO-BR-ST05-01 تا 04 استفاده کنید. 01 تکمیل، 02 مرجوعی، 03 توقف، 04 تمرین FFP آماده. داده شامل بیمار، پذیرش، درخواست، تأیید و گزارش آزمایش ساختگی، تجهیز با کد دستی، ثبت دما و سوابق آماده‌سازی است. تاریخ انقضای ساختگی صرفاً برای تمرین است و مبنای بالینی ندارد. هیچ داده واقعی یا تأیید بالینی واقعی seed نمی‌شود. Seed تکرارشونده پرونده‌های قبلی را تغییر نمی‌دهد و انقضا را تمدید نمی‌کند. برای تمرین مجدد از دیتابیس توسعه تازه یا داده جدید از فرم‌ها استفاده کنید.
