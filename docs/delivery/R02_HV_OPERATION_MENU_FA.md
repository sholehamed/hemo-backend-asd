## فعال‌سازی Development
HemoSeed__Enabled=true، HemoSeed__IncludeHemovigilance=true، HemoSeed__IncludeHvOperationPages=true. گزینه آخر صفحات خواندنی را نیز فعال می‌کند. تنظیمات مراحل قبلی حفظ شوند.
- /hemo/hv/new: منوی ثبت واکنش؛ hv-candidates، hv-report و hv-detail لازم هستند.
- /hemo/hv/detail/:guid: منوی خصوصی مخفی با hv-detail؛ نگاشت عملیات فقط به دارندگان مجوزهای موجود.
- مسئول هموویژیلانس، بازبین مستقل، پزشک، پرستار و بانک خون طبق Seed موجود. مسئول تخصیص از مجوز بازبینی مستقل برخوردار نمی‌شود. حساب یا زوج نقش/API تازه تعریف نشده است.
- داده ساختگی آموزشی از گزینه IncludeHemovigilanceSamples و تنظیمات نمونه وابسته موجود استفاده می‌کند؛ استفاده بالینی ممنوع.
