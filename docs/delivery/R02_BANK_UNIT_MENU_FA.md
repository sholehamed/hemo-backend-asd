# R02 — منوی دریافت و عملیات واحد بانک خون
مبنا: main 6cd85727؛ PR18 ادغام شده. همراه Frontend PR24.
## فعال‌سازی
Development: HemoSeed__Enabled=true، HemoSeed__IncludeBloodBank=true، HemoSeed__IncludeBankUnitPages=true. این گزینه صفحات خواندنی بانک را نیز فعال می‌کند. برای لینک جزئیات درخواست، گزینه‌های قبلی RequestDetailPages یا RequestFormPages حفظ شوند.
- /hemo/bank/receive: منوی قابل مشاهده؛ دریافت و مجوز مشاهده واحد لازم است؛ فقط API دریافت نگاشت می‌شود.
- /hemo/bank/unit/:guid: منوی خصوصی مخفی؛ مجوز مشاهده واحد لازم است. فقط عملیات بانک و صف/جزئیات درخواست که از قبل به نقش اعطا شده‌اند نگاشت می‌شوند.
- hemo.bloodbank: عملیات کارشناس طبق مجوزهای قبلی؛ hemo.bank.supervisor: بازرسی و امحا با مجوزهای قبلی. مدیر آمار به این صفحات دسترسی ندارد.
- هیچ زوج نقش/API جدید، مجوز کل منو یا عمومی، نقش یا حساب تازه، Migration یا اجرای Production ایجاد نمی‌شود. کنترل نسخه، وضعیت، مرکز و سایر قواعد همچنان در سرویس موجود انجام می‌شود.
## آزمون
یک تست سیاست جدید و توسعه تست SQL موجود برای ارتقا، دقیق بودن نگاشت، تکرارپذیری و حفظ مجوزها. CI و UAT واقعی هنوز تأیید نشده‌اند.
