## فعال‌سازی Development
HemoSeed__Enabled=true، HemoSeed__IncludeHemovigilance=true، HemoSeed__IncludeHvReportPages=true. گزینه آخر منوهای خواندنی و عملیاتی قبلی هموویژیلانس را فعال می‌کند. گزینه‌های سایر ماژول‌ها حفظ شوند.
- /hemo/hv/reports: نیازمند hv-reports و hv-report-detail؛ نگاشت مجوزهای موجود hv-stats، hv-archive و hv-report-external فقط برای نقش‌های دارای همان دسترسی.
- قابلیت reportDetail به پاسخ Capabilities افزوده شده است؛ مجوزهای API، کنترل مرکز و Guard موجود مستقل هستند.
- hemo.hv.officer: مشاهده، پیش‌نمایش، آرشیو و ثبت وضعیت بیرونی. hemo.hv.reviewer: مشاهده و پیش‌نمایش؛ بدون مجوز آرشیو یا ثبت وضعیت بیرونی. حساب تازه ایجاد نشده است.
- بک‌اند موجود آمار را هنگام ایجاد به صورت SnapshotJson ذخیره می‌کند؛ تغییر وضعیت بیرونی فقط متادیتای گزارش را به‌روزرسانی می‌کند.
## آزمون و محدودیت
یک تست سیاست نقش جدید و توسعه آزمون SQL ارتقا، نگاشت دقیق و تکرارپذیری. بدون Migration. CI و UAT واقعی هنوز تأیید نشده‌اند. API آرشیو موجود برای پاسخ گم‌شده کلید idempotency ندارد؛ ارسال رسمی خارجی پیاده‌سازی نشده است.
